silik-vpn-watcher для Windows
============================

Программа следит за выбранным VPN-профилем Windows и пытается восстановить
подключение после обрыва. Требуются Windows 10 или 11 x64 и .NET Framework
4.8. Установка и права администратора не нужны.

Как начать
----------
1. Распакуйте ZIP-архив и запустите silik-vpn-watcher.exe.
2. Выберите уже настроенный VPN-профиль Windows. Если список пуст,
   добавьте профиль в «Параметры → Сеть и Интернет → VPN» и нажмите
   «Обновить» в программе.
3. Если вход ещё не сохранён в Windows, нажмите «Подключить» и сохраните
   данные входа в диалоге Windows, если этот профиль это поддерживает.
4. Нажмите «Включить наблюдение». Если VPN отключён, программа сразу
   попробует его подключить. После обрыва она запустит новую попытку.

Управление из трея
------------------
Крестик скрывает окно в область уведомлений рядом с часами.
Если значок скрыт, нажмите стрелку вверх рядом с часами.
Двойной щелчок по значку возвращает окно. Правая кнопка показывает
текущий статус VPN и наблюдения и открывает команды
«Включить наблюдение», «Выключить наблюдение» и «Выход из программы».

Выключение наблюдения и выход останавливают повторы и сохраняют уже
подключённый туннель. Чтобы разорвать туннель, нажмите «Отключить»
в основном окне. При новом запуске наблюдение выключено.

Настройки и автоматический вход
------------------------------
По умолчанию проверка выполняется каждые 2 секунды, ожидание подключения
составляет 120 секунд, а пауза после ошибок растёт с 5 до 60 секунд.
Интервалы можно изменить в окне. Они сохраняются в
%LOCALAPPDATA%\VpnWatch\timers.txt.

Фоновый вход использует данные, сохранённые Windows. При отказе входа
или ошибке сертификата наблюдение останавливается. Проверьте ручное
подключение через Windows, затем снова включите наблюдение.
